# APA 自动泊车辅助系统

> 个人项目经历归档 · 2021.08 — 2023.03

---

## 项目简介

参与 **APA（Automatic Parking Assist）自动泊车辅助系统** 的研发工作。系统基于 **TC397 MCU + T507 Linux** 软硬件协同架构，涵盖环境感知、车位识别、决策控制与轨迹可视化等能力；感知、规划、控制、显示等模块之间通过 **CAN** 与 **UART** 进行数据交互。同步开发了基于 **Qt** 的在线调试工具，用于算法验证与问题定位。

系统支持 **自动泊入**、**自动泊出**、**自选车位**（垂直 / 水平）三大功能。

---

## 个人职责

- **通信模块开发**：负责 CAN 总线与 UART 通信模块，完成各模块（感知、规划、控制、HMI）间的数据传输、协议解析与状态同步，排查通信异常，保障系统联调稳定性。
- **网络协议实现**：基于 CAN 网络实现车辆状态、定位及控制指令的解析与封装；参与联合协议调试，通过报文抓取与分析定位问题。
- **决策状态机开发**：负责 APA 决策状态机逻辑，完善车位识别、流程切换、轨迹修正等逻辑；参与多场景联合调试与功能验证。
- **调试工具开发**：基于 Qt / QPainter / Socket 开发在线轨迹可视化调试工具，实时展示车辆轨迹、传感器信息与关键系统状态，支持数据回放与问题定位。
